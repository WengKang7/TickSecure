# Local interface fonts

The shared buyer, organizer, administrator and authentication layouts load these fonts locally through `assets/css/role-refresh.css`. No Google Fonts connection is required at runtime.

- **Manrope** variable (200–800): interface and body text. Source: https://github.com/google/fonts/tree/main/ofl/manrope
- **Space Grotesk** variable (300–700): the previous headings and display text. Source: https://github.com/google/fonts/tree/main/ofl/spacegrotesk

Original variable TTF files are included unmodified. Each font's SIL Open Font License and copyright notice are in its adjacent `OFL.txt` file.
